# النسخة النهائية الموحدة للدخول والعرض

## الملفات الرئيسية
- login.html: صفحة دخول موحدة للمديرين والمنسوبات، باسم المستخدم أو البريد الإلكتروني.
- index.html: صفحة المنسوبة، وقسم «مبادرات منسوبات المدرسة» يعرض الكود + اسم المبادرة + صاحبتها + الحالة فقط، بدون زر تفاصيل.
- admin.html: لوحة الإدارة، مع اسم مستخدم لحسابات المديرين.
- reset-password.html: إعادة تعيين كلمة المرور.
- initiative-view.html: صفحة تفاصيل المبادرة لصاحبة المبادرة/الجهة المصرح لها، وليست مرتبطة بزر في القائمة العامة.

## Supabase Edge Functions
- admin-create-user/index.ts
- admin-manage-user/index.ts

## مهم
تم إصلاح تعارض `supabaseClient` في login.html. الصفحة تستخدم عميل Supabase في متغير عام محمي باسم `__SCHOOL_SUPABASE_CLIENT__` ولا تعتمد على `supabase-config.js`.

لا تنفذ SQL جديدًا. دالة `resolve_login_email` التي تم تنفيذها سابقًا مطلوبة لدعم تسجيل الدخول باسم المستخدم.

## الاختبار
1. استبدل login.html.
2. استبدل index.html.
3. استبدل admin.html.
4. انشر Edge Functions المرفقة إذا لم تكن النسخة الأخيرة منشورة.
5. نفذ Ctrl+F5.
6. اختبر حساب منسوبة باسم المستخدم ثم بالبريد.
7. اختبر حساب مدير باسم المستخدم ثم بالبريد.
